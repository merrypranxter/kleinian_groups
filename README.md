# Kleinian Groups & Hyperbolic Geometry

![Python](https://img.shields.io/badge/python-3.8%2B-blue) ![License](https://img.shields.io/badge/license-MIT-green)

A Python library for exploring **Kleinian groups**, **Möbius transformations**, and the fractal geometry of **hyperbolic 3-manifolds**. Compute limit sets, generate Apollonian gaskets, visualize Ford circles, and estimate Hausdorff dimensions — all from first principles.

---

## Mathematical Background

### Möbius Transformations

A **Möbius transformation** (also called a linear fractional transformation) is a map on the Riemann sphere $\hat{\mathbb{C}} = \mathbb{C} \cup \{\infty\}$:

$$f(z) = \frac{az + b}{cz + d}, \quad a,b,c,d \in \mathbb{C},\quad ad - bc \neq 0$$

These are represented as $2 \times 2$ complex matrices:

$$f \leftrightarrow \begin{pmatrix} a & b \\ c & d \end{pmatrix} \in \mathrm{PSL}(2, \mathbb{C})$$

Composition of transformations corresponds to matrix multiplication. Every Möbius transformation is one of:

- **Parabolic**: $\mathrm{tr}^2 = 4$, one fixed point
- **Elliptic**: $\mathrm{tr}^2 \in (0, 4) \subset \mathbb{R}$, two fixed points, rotation-like
- **Hyperbolic**: $\mathrm{tr}^2 \in (4, \infty) \subset \mathbb{R}$, two fixed points, expansion/contraction
- **Loxodromic**: $\mathrm{tr}^2 \in \mathbb{C} \setminus \mathbb{R}$, spiral motion

### Kleinian Groups

A **Kleinian group** is a discrete subgroup $\Gamma \subset \mathrm{PSL}(2, \mathbb{C})$. It acts discontinuously on the upper half-space $\mathbb{H}^3$ and on its boundary, the Riemann sphere.

Key examples:
- **Schottky groups**: free groups generated by hyperbolic/loxodromic elements whose isometric circles are disjoint
- **Fuchsian groups**: Kleinian groups preserving the upper half-plane (e.g., $\mathrm{PSL}(2, \mathbb{Z})$)
- **Quasifuchsian groups**: deformations of Fuchsian groups

### Limit Sets

The **limit set** $\Lambda(\Gamma)$ is the set of accumulation points of any orbit $\Gamma \cdot z_0$. It is:
- Empty or 2 points for elementary groups
- A **Cantor set** for Schottky groups
- A **Jordan curve** for quasifuchsian groups
- The full Riemann sphere for groups of the second kind

The Hausdorff dimension $\delta = \dim_H(\Lambda)$ satisfies $0 < \delta < 2$ for non-elementary groups.

### Apollonian Gaskets

The **Descartes Circle Theorem** states that for four mutually tangent circles with curvatures $k_1, k_2, k_3, k_4$:

$$(k_1 + k_2 + k_3 + k_4)^2 = 2(k_1^2 + k_2^2 + k_3^2 + k_4^2)$$

Starting from a Descartes quadruple, iterating produces the Apollonian gasket — an infinite fractal packing. Every interstice is filled by a unique circle, and the entire configuration is invariant under Möbius inversion.

## Quick Start

```python
import sys
sys.path.insert(0, 'src')
from kleinian import Mobius, KleinianGroup, compute_limit_set

# Create a Möbius transformation: z -> (2z+1)/(z+1)
f = Mobius(2, 1, 1, 1)
print(f(1+1j))          # Apply to a point
print(f.trace())         # Compute trace
print(f.is_hyperbolic()) # True

# Build a Schottky group
import numpy as np
t = 0.8
A = Mobius(np.cosh(t), np.sinh(t), np.sinh(t), np.cosh(t))
phi = Mobius.rotation(np.pi/2)
B = A.conjugate_by(phi)

group = KleinianGroup([A, B], names=['a', 'b'])

# Compute limit set
pts = compute_limit_set(group, max_depth=8)
print(f"Limit set: {len(pts)} points")
```

## Examples

### `examples/schottky.py` — Schottky Group
Constructs a 2-generator Schottky group from hyperbolic Möbius transformations, applies the Jørgensen discreteness test, computes the limit set (a Cantor set), estimates its Hausdorff dimension, and renders it to `schottky_limit_set.png`.

```bash
python examples/schottky.py
```

### `examples/apollonian.py` — Apollonian Gasket
Verifies the Descartes circle theorem with curvatures $(-1, 2, 2, 3)$, iterates the Apollonian construction to fill the gasket, and saves the fractal to `apollonian_gasket.png`.

```bash
python examples/apollonian.py
```

### `examples/fuchsian.py` — PSL(2,ℤ) Modular Group
Constructs the modular group with generators $S: z \mapsto -1/z$ and $T: z \mapsto z+1$, verifies the relations $S^2 = (ST)^3 = I$, generates Ford circles (Farey tessellation), and plots both Ford circles and the orbit of $i$ to `fuchsian_modular.png`.

```bash
python examples/fuchsian.py
```

### `examples/quasifuchsian.py` — Quasifuchsian Deformation
Starts from a Fuchsian group and applies bending deformations at angles $\theta = 0, 0.15, 0.4, 0.8$ rad. Visualizes how the limit set deforms from a line to a fractal Jordan curve in `quasifuchsian_deformation.png`.

```bash
python examples/quasifuchsian.py
```

## API Reference

### `Mobius`
```python
Mobius(a, b, c, d)           # f(z) = (az+b)/(cz+d)
Mobius.identity()             # Identity transformation
Mobius.parabolic(t)           # z -> z+t
Mobius.hyperbolic(lambda_)    # z -> lambda*z
Mobius.rotation(theta)        # Rotation by theta
f(z)                          # Apply to point(s)
f * g                         # Compose
f.inverse()                   # Inversion
f.conjugate_by(phi)           # phi * f * phi^{-1}
f.fixed_points()              # Fixed points
f.trace()                     # Trace
f.isometric_circle()          # (center, radius)
f.is_parabolic/elliptic/hyperbolic/loxodromic()
```

### `KleinianGroup`
```python
KleinianGroup([A, B], names=['a','b'])
group.word_to_mobius('abAB')  # Evaluate word
group.enumerate_words(depth)  # BFS word enumeration
group.orbit(z0, max_depth)    # Orbit of a point
group.jorgensen_number(A, B)  # Jørgensen inequality value
```

### Limit Set
```python
compute_limit_set(group, max_depth=8, tol=1e-6)
isometric_circle_limit_set(group, max_depth=6)
hausdorff_dim_estimate(points)
```

### Circle Packing
```python
descartes_step(k1, k2, k3)          # Fourth Descartes curvature
apollonian_gasket(k1,k2,k3,k4, max_iter=5)  # Full gasket
ford_circles(max_q=20)              # Ford circles for Farey fractions
circle_inversion(center, radius, z) # Invert point in circle
```

### Discreteness Tests
```python
jorgensen_test(A, B)                 # Jørgensen inequality
is_elementary(group)                  # Elementary group test
ping_pong_test(A, B, D_A, D_B)       # Ping-pong lemma
```
